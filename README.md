## 🚀 Capacidades y Módulos de la Plataforma

* 🔄 **Sincronización Bidireccional de Inventario:** Conciliación automatizada cada 15 minutos entre el POS físico (RetailEdge) y la tienda online oficial (debleusupply.ky).
* ☁️ **Túnel Remoto Seguro (Cloudflare):** Acceso móvil cifrado de extremo a extremo sin necesidad de abrir puertos ni configurar IP pública.
* 📱 **Mobile Picking Hub:** Interfaz móvil interactiva para el escaneo de códigos de barra y preparación de pedidos desde cualquier smartphone.
* 📊 **Módulo de Reportes y Auditoría:** Supervisión de órdenes completadas vs. órdenes con incidencia (falta de stock, cancelaciones, devoluciones) con exportación a Excel / CSV.
* 📶 **Portal Cautivo Wi-Fi para Clientes:** Generación instantánea de credenciales y carteles de acceso para clientes en tienda física.
* 🔄 **Auto-Updater Inteligente:** Verificación de versiones multi-espejo en tiempo real con descarga diferencial acelerada vía `.blockmap`.

## 🛠️ Guía de Instalación y Primer Uso

### 1. Instalación Estándar (Recomendada)
1. Descargue el archivo **`Debleu.Supply.Setup.1.0.1.exe`**.
2. Haga doble clic para iniciar el instalador.
3. El programa creará automáticamente el acceso directo en el Escritorio y en el Menú Inicio.
